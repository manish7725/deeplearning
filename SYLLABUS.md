# Deep Learning Syllabus

## 1. Foundations
- Python, NumPy and PyTorch
- Vectors, matrices, tensors and linear transformations
- Probability, statistics and basic calculus

## 2. Neural Networks
- Perceptron and neurons
- Forward propagation
- Activation functions
- Loss functions
- Matrix formulation of neural networks
- Backpropagation and computational graphs

## 3. Optimization
- Gradient descent
- Learning rate and convergence
- SGD, Momentum and Adam
- Weight initialization
- Regularization and normalization

## 4. Convolutional Neural Networks
- Convolution and kernels
- Padding, stride and pooling
- CNN architectures
- Transfer learning

## 5. Sequence Models
- RNNs
- Vanishing and exploding gradients
- LSTM and GRU
- Sequence-to-sequence learning

## 6. Attention and Transformers
- Embeddings
- Query, Key and Value
- Self-attention
- Multi-head attention
- Positional encoding
- Transformer encoder and decoder
- Large Language Models

## 7. Generative Deep Learning
- Autoencoders and VAEs
- GANs
- Diffusion models

## 8. Practical Deep Learning
- Dataset preparation
- Training and validation
- Evaluation metrics
- Experiment tracking
- GPU training
- Model deployment

## Learning Principle
Build every concept from first principles: intuition → mathematics → matrix/tensor formulation → PyTorch implementation → practical example.
