# Lecture 01 — Preread Exercises

Before starting Lecture 01, complete these three small Google Colab notebooks. They are designed as a **hands-on warm-up**, not as a separate course in Python or mathematics.

You do not need to memorize everything. The goal is to become comfortable enough with the tools that Lecture 01 can focus on the ideas of machine learning.

Learn the minimum Python needed for the course: variables, numbers, lists, loops, functions, and running cells in Colab.
