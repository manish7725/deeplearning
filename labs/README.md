# Deep Learning Hands-on Lab Track

Every concept in the chapter folders (see [`CHAPTERS.md`](../CHAPTERS.md)) now has a companion lab. The rule for this series is:

> **Read the idea → derive the math → run the code → change the code → explain the result.**

## Resource philosophy

Use the blogs as the primary self-contained lessons. Use external resources when you want a second explanation or deeper intuition.

### Recommended visual / conceptual channels

- Frame Zero — first-principles machine-learning intuition
- ZacharyLLM — modern LLM and AI-systems perspective
- Welch Labs — visual storytelling for mathematics, neural networks and AI
- MrJensenMath10 — mathematical foundations and problem-solving
- Visual Kernel — visual/technical computing intuition
- 3Blue1Brown — especially linear algebra, calculus, neural networks, attention and transformers

### Official references

- PyTorch Tutorials: tensors, autograd, neural networks, optimization and complete workflows.
- scikit-learn User Guide: classical ML algorithms, evaluation and practical modeling.
